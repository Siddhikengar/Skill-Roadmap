# Skill-Roadmap : Engineering Skill Recommender

**Live Demo** - (https://skill-roadmap.onrender.com)

A web app that helps engineering students and professionals discover the **next skills to learn** for their chosen domain and job role.  
Users simply pick their engineering domain, select a role, check the skills they already know, and receive a **personalized learning roadmap**.

---

## 🚀 Features
- **Domain & Role Selection** – Choose from Software/Data, Core Engineering, Emerging Tech, Biotech/Biomedical, and more.  
- **Skill Gap Analysis** – Compare your current skills with role-specific requirements.  
- **Learning Resources** – Each recommended skill is paired with curated YouTube links for quick learning.  
- **Responsive UI** – Works on desktop and mobile.
